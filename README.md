# Weather-API-Application

A weather app built with HTML, CSS, and JavaScript that lets users search for a city and view current weather information such as temperature, condition, humidity, and wind speed.

## Features

- Search weather by city
- Display current temperature
- Show weather condition and icon
- Show humidity, wind, and feels like temperature
- Loading state while fetching data
- Error handling for invalid searches
- Search with button or Enter key

## Built With

- HTML
- CSS
- JavaScript
- WeatherAPI

## What I Practiced

- Fetch API
- async/await
- working with API data
- conditional rendering
- loading and error states
- modular JavaScript structure
